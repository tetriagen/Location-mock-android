Mock Location Lab — учебный мокер и детектор

Android 8.0+ (API 26), исходники Java. Интернет не используется.

Стенд подаёт тестовую позицию через собственный провайдер edu_mock_lab,
получает её обратно от LocationManager и показывает системный флаг mock.
Провайдеры gps/network/fused не заменяются. Это не средство скрытой
подмены координат в сторонних приложениях.

В детекторе воспроизведена подтверждённая в разобранном примере проверка:
Android 12+ — Location.isMock(), более ранние — isFromMockProvider().
Точность <= 50 м и возраст <= 10 секунд — дополнительные учебные правила
данного стенда; они не взяты из Clockster и не описывают его полную логику.

Запуск

1. Установить dist/mock-location-lab.apk на тестовое Android-устройство.
2. Включить системное «Местоположение».
3. В «Для разработчиков» выбрать Mock Location Lab как приложение
   для фиктивных/тестовых местоположений. Название пункта зависит от телефона.
4. Открыть приложение, разрешить точную геопозицию, нажать «Подать точку».
5. Сравнить результаты двух учебных проверок:
   - обычная точка с accuracy=5: правдоподобие пройдено;
   - та же точка: isMock=true, проверка с учётом флага отклоняет её;
   - accuracy=500: не проходит уже проверку правдоподобия.

В поле isMock показывается значение только из callback Android.
Состояние локально созданного объекта Location не выдаётся за измерение ОС.
Одиночный тест останавливается при уходе с экрана. Поток 1 Гц использует
foreground service, провайдер edu_mock_lab_stream и уведомление со Стоп.
Он продолжает работать при сворачивании и выключенном экране.
Android может остановить процесс; автоматического перезапуска нет.
Поток удерживает CPU wake lock, поэтому расходует дополнительную батарею.
Для нового измерения детектором остановите поток и нажмите Подать точку.
После эксперимента можно снять выбор приложения mock-геопозиции в настройках.

Сборка

Нужны Python 3, JDK 17, Android SDK Platform 36 и Build Tools 36.0.0.
Gradle, AndroidX и внешние Java-библиотеки не требуются.

python3 tools/build.py --java-home /path/to/jdk-17 --sdk /path/to/android-sdk

Также поддерживаются JAVA_HOME и ANDROID_SDK_ROOT/ANDROID_HOME.
Скрипт компилирует Java, преобразует DEX, собирает и подписывает APK,
проверяет подпись и выравнивание, затем запускает тесты политики.
Для демонстрации создаётся локальный debug-ключ с паролем android.
Сохраняйте build/lab-debug.p12 для установки следующей сборки поверх этой.
В исходный архив debug-ключ не включён.

Исходники

app/src/main/java/edu/mocklab/MainActivity.java — UI, mock-провайдер, callback.
app/src/main/java/edu/mocklab/LocationPolicy.java — две учебные проверки.
tests/LocationPolicyTest.java — тесты значений и границ без Android.

Границы проверки

Сборка и тесты Java-политики не заменяют запуск на Android.
Для проверки на устройстве: отказ в разрешении, приблизительная геопозиция,
не выбранный mock-app, выключенное местоположение, одиночная точка, поток,
остановка, сворачивание и поворот экрана. Ожидается отсутствие фоновой подачи
после остановки. Отсутствие mock-метки само по себе не доказывает подлинность.
